# Examples

Example games and classroom demonstrations for **Pygame Zero Plus** are maintained in a separate repository:

**[CS4040 Game Design — Code Examples](https://github.com/mjdargen/cs4040)**

The collection includes introductory examples of drawing, movement, input, collisions, and game state, along with sprite animations, projectiles, and larger platformer and top-down game demonstrations.

The examples and their supporting assets are kept separate from the `pgzero-plus` library so they can be updated independently. See the [CS4040 README](https://github.com/mjdargen/cs4040#readme) for setup instructions and to explore the examples.
